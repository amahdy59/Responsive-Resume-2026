Sales Performance Dashboard

CRM sales dashboard built in Google Sheets for tracking quarterly team performance through chart-based visualization.

Role: Data Analyst Timeline: 1 Month
View Live Project
Live evidence: This project is available through the link above. A verified local portfolio image has not been added, so no placeholder is shown.

Context & challenge

Sales managers lacked a clear, real-time view of individual and team performance metrics. Existing reports were static, hard to read, and required manual weekly updates.

Approach & key decisions

I designed an automated, visually striking dashboard directly within Google Sheets. By utilizing advanced conditional formatting, pivot tables, and custom charts, I transformed raw CRM exports into a self-updating, highly readable performance tracker.

Tools & Technologies

Microsoft Excel (Advanced) Google Sheets KPI Analysis Dashboard Design

Outcome & reflection

Constraints breed creativity. Building a beautiful, functional dashboard within the limitations of a spreadsheet application taught me how to push the boundaries of conditional formatting and layout grids to mimic dedicated BI tools.
