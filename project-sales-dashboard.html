Sales Performance Dashboard

CRM sales dashboard built in Google Sheets for tracking quarterly team performance through chart-based visualization.

Role: Data Analyst Timeline: 1 Month
View Live Project
Live evidence: This project is available through the link above. A verified local portfolio image has not been added, so no placeholder is shown.

Context & challenge

The project addresses the challenge of comparing individual and team sales performance inside a familiar spreadsheet environment without requiring a separate BI platform.

Approach & key decisions

As data analyst, I organized CRM exports with pivot tables, conditional formatting, and focused charts so quarterly KPIs can be scanned and compared in Google Sheets.

Tools & Technologies

Microsoft Excel (Advanced) Google Sheets KPI Analysis Dashboard Design

Outcome & reflection

The implementation shows how a spreadsheet can support a compact decision view without imitating every feature of a dedicated BI tool. The next validation step is to measure refresh effort, error rate, and manager task time.

Evidence & next validation

The published dashboard is the current evidence. Source-data refresh timing, manager task testing, and production adoption metrics have not been published and are not claimed as outcomes.
