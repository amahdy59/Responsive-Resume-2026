Cairo International Airport - Command Hub

A high-fidelity operational command dashboard focusing on real-time data visualization, clear information hierarchy, and responsive performance.

Role: UX/UI Designer & Data Visualizer Timeline: 4 Months
View Live Project

Context & challenge

The concept addresses a high-density operational environment where flight status, terminal activity, and maintenance information need a clear shared hierarchy.

Approach & key decisions

As UX/UI designer and data visualizer, I organized the dashboard around critical alerts, high-level KPIs, and progressive drill-down into terminal detail. The dark interface supports sustained viewing, but reduced eye strain has not been clinically or operationally measured.

Tools & Technologies

Figma Information Architecture Data Visualization Dashboard Design

Outcome & reflection

The implementation demonstrates how progressive disclosure can balance dense operational data with scanning. The next step is scenario-based testing with representative operations users under realistic time pressure.

Evidence & next validation

The interface capture and working dashboard are available for review. Operational user interviews, task timings, and production performance metrics have not been published and are not claimed here.
