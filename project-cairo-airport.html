Cairo International Airport - Command Hub

Real-time interactive operational dashboard monitoring flight arrivals, departures, and terminal status.

Role UX/UI Designer & Data Visualizer
Timeline 4 Months
Platform Operational Desktop & Tablet SaaS
Status Interactive Prototype Live
View Live Project

01 Context & Challenge

Airport ground operations staff needed a unified command dashboard to monitor terminal zones, gate allocations, and flight statuses with zero latency in high-stress operational environments.

02 Approach & Key Decisions

Built a high-contrast dark visual command interface with modular real-time telemetry cards, interactive terminal digital twins, and instant incident status triage.

Architectural UX Decision

Implemented custom color-coded status badges with shape distinctions to ensure mission-critical clarity under diverse lighting conditions.

03 Tools & Technologies

Figma Dashboard UX Real-Time Telemetry Information Architecture Design Systems WCAG 2.2 AAA

04 Outcome & Impact

Reduced flight delay incident response times and simplified ground crew coordination through unified situational awareness.

05 Evidence & Next Validation

Interactive prototype is deployed live for stakeholder simulation and ongoing operational stress testing.
