# Internationalization contract

English and Arabic are equal supported locales. Source copy lives in the `translations` dictionaries in `script.js`; `npm run check` rejects missing keys. The build emits crawlable static routes under `/en/` and `/ar/`, plus localized case-study routes, canonical URLs, `hreflang` links, a sitemap, and a JavaScript-free baseline.

Locale precedence is URL, saved preference, browser language, then English. Arabic uses RTL and Cairo; English uses LTR and Inter. UI language names remain native: English and العربية. A locale switch on a localized route navigates to the equivalent route in the other locale.

Do not concatenate translated fragments. Add a complete sentence key, translate accessible names and metadata with the visible copy, and test both directions at 320 px before merging.
