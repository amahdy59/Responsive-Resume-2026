A Data-Driven LEGO Explorer

An interactive Tableau visualization experience that helps users explore LEGO sets by theme, age, price, and set count.

Role: Data Analyst & Visualizer Timeline: 2 Months
View Live Project
Live evidence: This project is available through the link above. A verified local portfolio image has not been added, so no placeholder is shown.

Context & challenge

LEGO enthusiasts and buyers often struggle to compare sets across massive product catalogs. The goal was to take a large, raw dataset of LEGO sets and turn it into an engaging, explorable tool for users of all ages.

Approach & key decisions

I developed a highly interactive Tableau dashboard utilizing dynamic filtering. Users can visually explore distributions of price-per-piece, track theme popularity over time, and isolate specific categories using an intuitive, playful interface.

Tools & Technologies

Tableau Data Storytelling Data Analytics UI Design

Outcome & reflection

Data visualization isn't just about charts; it's about storytelling. I learned how to use color strategically—mapping specific Tableau color palettes to iconic LEGO colors to make the dashboard feel thematic and immersive rather than purely analytical.
