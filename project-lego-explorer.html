A Data-Driven LEGO Explorer

An interactive Tableau visualization experience that helps users explore LEGO sets by theme, age, price, and set count.

Role Data Analyst & Visualizer
Timeline 2 Months
Platform Tableau Public Visualization
Status Published Live
View Live Project

01 Context & Challenge

A massive 50-year dataset of over 18,000 LEGO sets presented overwhelming tabular data that prevented casual collectors and analysts from discovering pricing trends and theme growth.

02 Approach & Key Decisions

Cleaned and structured the dataset, then designed an interactive dual-axis visual analytics dashboard in Tableau allowing dynamic filtering by release decade, piece count, and target demographic.

Key Design Decision Engineered responsive cross-filtering across bar charts and scatter plots, allowing users to select any individual theme and instantly view median price per piece curves.

03 Tools & Technologies

Tableau Data Analysis Information Design Data Modeling Interactive Dashboards

04 Outcome & Impact

Transformed raw historical sales and catalog records into an engaging, decision-ready data storytelling tool.

05 Evidence & Next Validation

Interactive Tableau project is live on Maven Showcase for exploration and download.
