A Data-Driven LEGO Explorer

An interactive Tableau visualization experience that helps users explore LEGO sets by theme, age, price, and set count.

Role: Data Analyst & Visualizer Timeline: 2 Months
View Live Project
Live evidence: This project is available through the link above. A verified local portfolio image has not been added, so no placeholder is shown.

Context & challenge

The project explores how a large LEGO dataset can become a more approachable comparison tool across theme, age, price, and set size.

Approach & key decisions

As data analyst and visualizer, I built dynamic Tableau filters for price-per-piece, theme trends, age ranges, and category comparison while using a restrained LEGO-inspired color system.

Tools & Technologies

Tableau Data Storytelling Data Analytics UI Design

Outcome & reflection

The result demonstrates a thematic visual system without turning color into the only carrier of meaning. The next validation step is task-based testing of filter discoverability and comparison accuracy.
